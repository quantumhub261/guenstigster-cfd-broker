## 3. Исправленные дефекты

**Критичные**

1. **Коллизия CSS-класса `.rv`** — класс использовался одновременно для значений калькулятора (моношрифт) и для reveal-анимации (`opacity:0`). Из-за этого результаты калькулятора были невидимы до попадания в вьюпорт. Класс калькулятора переименован в `.rvl`.

2. **Пустая страница при отключённом JS** — весь контент лежал под `.rv{opacity:0}` и показывался только через IntersectionObserver. Если JS заблокирован или observer не сработал, пользователь видел пустую страницу. Теперь: правило действует только при классе `.js` (ставится инлайн-скриптом в `<head>`), плюс failsafe-таймер на 1.5 с, который раскрывает всё, если ни один reveal не сработал.

3. **Горизонтальный скролл на мобильных** — на 375px страница расширялась до 596px (сетка Quick Facts и шапка не помещались). Исправлено: `minmax(min(100%,…),1fr)`, `min-width:0` для grid-детей, одноколоночные Quick Facts и скрытие CTA в шапке ниже 480px. Проверено на 375 / 480 / 768 / 1024 / 1440 — горизонтального скролла нет.

4. **Недостоверная маркировка «Live»** — DAX и Gold захардкожены и никогда не запрашиваются, EUR/USD при недоступности API оставался со старым значением, но всё это было под пульсирующим бейджем «Live». Для финансового сайта это вводит в заблуждение. Теперь: значения без реального запроса помечены «Indikativ», бейдж «Live» загорается только при успешном ответе, под дашбордом выводится строка состояния с временем последнего обновления и перечнем реально обновлённых инструментов.

**Прочие**

5. **§ 5 TMG — доступность Impressum** — на внутренних страницах не было ссылок на Impressum и Datenschutz (по немецкому праву они должны быть доступны с каждой страницы). Добавлен единый правовой футер на все 7 подстраниц.

6. **`llms.txt` — сломанные умляуты** — `Vollstaendiger`, `Primaerquellen`, `brokerabhaengig`, `S20 Abs. 6`. Файл переписан корректной немецкой орфографией и дополнен.

7. **`content.md` — потерянные разделы** — вернулись «Kostenstruktur», «Regulierungshierarchie», строки таблиц (Ausführung, Requote-Risiko), Einlagensicherung; добавлены разделы Swap, CFD vs. ETF, налоги, методика.

8. **`sitemap.xml` — невалидный `changefreq`** — значение `quarterly` не входит в протокол sitemaps.org и игнорируется. Заменено на `monthly`.

9. **`robots.txt` — конфликт Disallow и noindex** — `Disallow: /impressum.html` не давал краулеру прочитать `noindex` на самой странице, из-за чего URL всё равно мог попасть в выдачу. Disallow снят, работает мета-тег.

10. **Размер шрифта < 12px** — дизайн-система прямо запрещает `font-size < 12px` в видимом контенте; в сборке было 45 объявлений на 10–11px (в т.ч. текст рисковых предупреждений). Всё поднято до 12px.

11. Добавлена поддержка `prefers-reduced-motion`, `min-width:0` для grid-контейнеров, утилита `.sr-only` для caption таблицы.

## 3a. Ревизия 2 — правки по запросу

**Убрана верхняя плашка Risikohinweis.** Amber-баннер между шапкой и hero удалён вместе с его CSS (`.rr`, `.rri`) — «мёртвых» стилей не осталось.

Предупреждение о риске при этом никуда не делось, проверено автоматически:

- дисклеймер в hero — «CFDs sind komplexe Instrumente. 65–80 % der Retail-Kunden verlieren Geld»;
- amber-врезка в блоке «Was kostet ein CFD Trade wirklich?»;
- полноразмерная секция Risikohinweis перед футером;
- юридический текст в футере;
- прямая ссылка на `risikohinweis.html` — теперь ещё и во втором уровне меню.

Формулировка «65–80 %» встречается на странице 7 раз. Требование ESMA о раскрытии Gesamtverlustkennzahl выполняется.

**Второй уровень меню выровнен и получил ссылки на внутренние страницы.** Строка была просто хлебными крошками; теперь это полноценная панель второго уровня:

- слева — хлебные крошки, слева направо выровнены по логотипу шапки (обе кромки в 51 px от края экрана при 1440 px);
- справа — ссылки на внутренние посадочные: Methodik, Quellen, Redaktion, Risikohinweis, Kontakt. Правая кромка совпадает с правой кромкой CTA-кнопки в шапке;
- обе группы отцентрованы по вертикали в строке высотой 46 px;
- на ≤768 px крошки скрываются, ссылки превращаются в горизонтально прокручиваемую ленту внутри строки — горизонтального скролла самой страницы не появляется;
- высота тап-таргета на мобильных — 36 px.

**`BreadcrumbList` приведён в соответствие с видимой цепочкой.** Средний уровень «CFD Broker Vergleich» вёл на якорь `#kosten` той же страницы, то есть ссылался сам на себя. Он убран из видимых крошек, и schema сокращена с 3 до 2 уровней — структурированные данные обязаны отражать то, что реально видит пользователь, иначе это повод для ручных санкций Google.

**Что это даёт для SEO.** Пять внутренних страниц теперь получают ссылку с главной в сквозном элементе, а не только из футера: глубина обхода сокращается, распределение веса по методике, источникам и редакции улучшается — это ровно те страницы, которые отвечают за E-E-A-T.

## 6. Примечания

- **CSS и JS инлайн, папки `assets/` нет.** В ТЗ была структура `assets/css/main.css` + `assets/js/main.js`. Оставлена инлайн-подача: это устраняет два блокирующих запроса и соответствует пункту чек-листа «CSS inline oder minifiziert, JS am Ende». Если нужна файловая структура — стили и скрипты выносятся без изменений в логике.
- **Внешние API.** EUR/USD берётся с `api.frankfurter.app`, BTC — с `api.coingecko.com`. При локальной проверке frankfurter.app блокировался CORS; с боевого домена он обычно отдаёт нужные заголовки. В любом случае отказ обрабатывается корректно: значение помечается «Indikativ», страница не ломается. Оба домена уже перечислены в `datenschutz.html`.
- **Даты.** Везде проставлен январь 2026 как дата публикации и проверки, следующая ревизия — апрель 2026. Перед реальным запуском даты стоит привести к фактическим.
- Авторы (Marcus Weber, Dr. Sabine Hoffmann) — вымышленные персоны из ТЗ. Для соответствия E-E-A-T под реальными данными их нужно заменить на настоящих людей либо снять указание на авторство.
